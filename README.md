# ML-mountains-vs-beaches

This project implements a Machine Learning pipeline for predicting user preferences between mountains and beaches.

The project covers the full workflow:
- data preprocessing
- exploratory data analysis
- model training
- model evaluation and comparison

---

## 📊 Technologies

- Python
- Scikit-learn
- Pandas
- NumPy

---

## 🚀 Workflow
1. Data loading and exploration  
2. Data preprocessing  
3. Model training (multiple algorithms)  
4. Model evaluation and comparison  

---

## 🤖 Models Used

- Decision Tree  
- Random Forest  
- K-Nearest Neighbors  
- Support Vector Machine  
- Naive Bayes  
- Neural Networks  

---

## ▶️ How to Run

```bash
pip install -r requirements.txt
# Then open the notebook:
jupyter notebook
```

---

## 📈 Goal

The goal of this project is to demonstrate a complete Machine Learning workflow, from raw data to model evaluation.
